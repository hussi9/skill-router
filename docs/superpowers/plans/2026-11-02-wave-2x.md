### Task N2: Calibrate keyless overlap against Jev

**Files:** Create `scripts/calibrate_overlap.py`, `tests/test_calibrate_overlap.py`; Modify `scripts/skill_audit.py` (threshold constant from calibration), `docs/skill-audit.md`, `.gitignore`.

**Interfaces:** `collect(catalog, jev, max_pairs=400) -> list[tuple[str, str, float, float]]` (a, b, jaccard, jev_prob) over candidate pairs with Jaccard ≥ 0.2; `best_threshold(rows, target=0.8) -> dict` choosing the Jaccard threshold in 0.20–0.90 (step 0.05) that maximises F1 against Jev labels (label = jev_prob ≥ 0.8), returning `{"threshold", "precision", "recall", "f1", "labels": n}`. CLI writes labels to `~/.claude/skill_router_cache/overlap-labels.jsonl` (git-ignored, mode 600) and prints the summary.

- [ ] Steps: failing tests (`test_best_threshold_maximises_f1` on synthetic rows; `test_no_key_leaves_threshold_unchanged`; `test_labels_file_is_private`) → implement → run once live on the author's machine → set `KEYWORD_OVERLAP_MIN` in skill_audit.py to the chosen threshold, record precision/recall/F1 and n in docs/skill-audit.md → commit "Calibrate keyless duplicate detection against Jev's verdicts".
