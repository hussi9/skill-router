# Wave 4.x — measure the real listing — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the simulated skill listing with the one Claude Code actually sends, measured from `/context`, in the audit, the visibility planner and doctor.

**Architecture:** `scripts/listing_probe.py` runs `claude -p "/context"` in a project on explicit request, parses the Skills row and the per-skill table, and caches the result per project key. Consumers prefer a fresh measurement and fall back to the simulation, always saying which they show.

**Tech Stack:** Python 3.11+ stdlib; pytest.

**Spec:** `docs/superpowers/specs/2026-11-02-skill-router-v3-vision.md`; retro `docs/superpowers/retros/2026-11-02-wave-4.md` (X3).

## Verified inputs

| Input | Verified how | Result |
|---|---|---|
| `claude -p "/context" --output-format text` | Run on 2026-11-02 in two projects | Markdown with `## Context Usage`, a category table containing `| Skills | 9.8k | 1.0% |`, and `### Skills` table rows `| <name> | <source> | <tokens> |` where tokens is `< 20` (name only) or `~N` (described); ~60 s per run; `SKILL_ROUTER_OFF=1` keeps the router out of the child session |

## Global Constraints

- The probe runs only on explicit command (`cli.py listing measure`); never from a hook or doctor. It prints that it starts a Claude Code session and roughly how long it takes.
- Child session: `SKILL_ROUTER_OFF=1`, timeout 300 s, cwd = the project; no prompt beyond `/context`.
- Cache: `~/.claude/skill_router_cache/listing/<project_key>.json`, mode 600, atomic write; holds skill names (local only), sources, token figures, totals, `measured_at`, context size line. Fresh = < 7 days.
- Committed files and docs carry counts only.
- Tests: parser on synthetic `/context` text; subprocess stubbed; suite-wide temp HOME and live guard apply.
- Commits intent-first, ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **`/context` output format changes** (missing Skills section, new columns). Expected: parser returns None with a one-line reason; consumers fall back to simulation. Test: `test_unknown_format_returns_none`.
2. **Claude not installed or not logged in.** Expected: one-line error, exit 1, cache untouched. Test: `test_claude_missing_is_clean_error`.
3. **Stale cache.** Expected: shown with its age and marked stale after 7 days; never silently used as current. Test: `test_stale_measurement_is_labelled`.
