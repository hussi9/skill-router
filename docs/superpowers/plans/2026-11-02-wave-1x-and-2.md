# Wave 1.x fixes and Wave 2 (`skill doctor`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the Wave 1 retro's gaps, then ship a 30-second audit that tells any user what their installed skills cost and which are dead weight.

**Architecture:** Wave 1.x hardens the existing hooks (hygiene gate, live-install drift, payload shape capture, cheaper Bash hook, holdout side effects). Wave 2 adds `scripts/skill_audit.py` (pure engine over the catalog, usage, outcomes and skills.sh cache) rendered by `scripts/cli.py audit`, plus one advisory doctor line. Jev, when a key is present, judges duplicate pairs; the keyless path uses keyword overlap.

**Tech Stack:** Python 3.11+ stdlib; pytest; Jev (`jev-1.13.0`) optional.

**Spec:** `docs/superpowers/specs/2026-11-02-skill-router-v3-vision.md`; retro: `docs/superpowers/retros/2026-11-02-wave-1.md`; parent plan: `docs/superpowers/plans/2026-11-02-skill-router-v3.md` (Wave 2 section).

## Global Constraints

- Two modes always: with `TYPESAFE_API_KEY` (Jev) and with no key; both tested (R1).
- The audit is CLI-only and never prints into a session (R2). Hook lines keep the existing rules: ≤ 200 chars, work turns only.
- No prompt text, no `$HOME` paths beyond `~`, no personal names in any committed file, test fixture or report (R4).
- Never install, remove, disable or edit a skill; the audit only recommends (R5).
- Tests offline; no reads of the developer's live `~/.claude` unless `SKILL_ROUTER_CHECK_LIVE=1`.
- Gate: `bash scripts/check.sh` passes; fresh-clone run passes.
- Commits intent-first, ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A pattern file missing on a contributor's machine.** Expected: the hygiene step is skipped with one line, never fails a clean clone. Test: R1 `test_missing_pattern_file_skips`.
2. **A skill description containing markdown/HTML or control characters in the audit report.** Expected: escaped in md/html, stripped in text. Test: 2.2 `test_report_escapes_descriptions`.
3. **No usage data at all (new install).** Expected: the audit says "no usage history yet" instead of calling every skill unused. Test: 2.1 `test_no_history_means_no_unused_verdict`.
4. **Jev slow or failing during duplicate checks.** Expected: falls back to keyword overlap for the remaining pairs within the time budget. Test: 2.1 `test_jev_failure_falls_back_to_keyword_overlap`.
5. **1,200 skills.** Expected: keyless audit < 2 s. Test: 2.1 `test_audit_runs_on_1200_synthetic_skills_under_2s`.

## Wave 2 — `skill doctor` for everyone

### Task 2.1: Audit engine

**Files:** Create `scripts/skill_audit.py`, `tests/test_skill_audit.py`.

**Interfaces:**
```python
@dataclass(frozen=True)
class AuditReport:
    skills: int
    listing_tokens: int            # sum(len(name) + len(description)) // 4 over routable skills
    unused_90d: list[str]          # empty when history_days < 30
    history_days: int              # span of usage history available
    shown_never_loaded: list[str]  # outcomes: shown >= 5 times, loaded 0 (empty without outcomes)
    overlaps: list[tuple[str, str, float, str]]  # (a, b, score, "jev"|"keyword")
    flagged: list[str]             # skills.sh audit "flagged" for installed names
    score: int                     # 0-100
    top_actions: list[str]         # <= 3 one-line recommendations

def audit(catalog: list[dict], usage: dict[str, int], history_days: int,
          outcomes: dict | None, skills_sh: dict | None,
          jev: Callable[[list[tuple[str, str]]], dict[tuple[str, str], float]] | None = None,
          budget_s: float = 10.0) -> AuditReport
def load_inputs() -> tuple[list[dict], dict[str, int], int, dict | None, dict | None]
```
**Rules:** keyword overlap = Jaccard of description token sets (reuse `index_match.tokenize`) ≥ 0.6 between skills of the same `kind`; with a Jev callable, candidate pairs with Jaccard ≥ 0.3 (max 200 pairs, batched ≤ 20 per call via Noul "Do these two agent skills do the same job?") count at probability ≥ 0.8; on Jev failure or budget exhaustion the remaining pairs use keyword overlap. Score = 100 − min(30, unused share × 60) − min(25, overlaps × 3) − min(25, flagged × 25) − min(20, max(0, listing_tokens − 8000) // 500). `top_actions` names the largest deduction first.
