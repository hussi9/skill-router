# Wave 3 retro (2026-11-02)

## What worked
- **The feasibility spike cut the wave in half.** Timing the hook showed a warm daemon would save ~30–60 ms against a ~400 ms Jev call, so `routerd` was dropped before any code was written. Only the MCP server shipped.
- **Live verification caught what tests missed.** A fix round made the server silently route without Jev on a machine that has a key; the controller's live round trip caught it, and a test now pins it.
- **The server keeps the router's promises:** read-only tools, no LLM fallback, Jev cache redirected to a temp dir, stdout carries only JSON-RPC.

## What did not
1. A fix in one place (disabling the LLM fallback) changed Jev's gate elsewhere (`_jev_active` read the same variable). Shared env flags with two meanings are fragile.
2. The keyless route still gives poor answers on real prompts (a Notion clean-up routed to a UI skill) — known since Wave 1, unchanged.

## Now-fixes
- **Live install synced** (backups kept): the live copy now runs this branch, hooks reinstalled (+PostToolUseFailure), doctor reports "live install in sync". Wave 1's outcome recording, holdout and Jev shortlist are now live; real data starts accumulating.
- Separating the two meanings of `SKILL_ROUTER_LLM` (tie-break vs Jev gate) is recorded as a follow-up; the MCP server pins the behaviour it needs.

## Next-wave decision
The remaining waves depend on things not yet available:
- **Wave 5 (local chooser distilled from Jev)** needs the training data that only now starts recording live — revisit after ~2 weeks of sessions.
- **Wave 6 (routing through the whole task)** benefits from the same outcome data to judge which triggers help.
- **Wave 7 (ecosystem: skill CI, lockfile, public report, shared outcomes)** is owner-gated by design.
- **Task 2.4 (re-measure Wave 1 out of sample)** becomes possible after a week of live data.

So the next step is release and data collection, not more code: the owner reviews and approves the squash, push and tag; the router collects outcomes; the next session starts with Task 2.4 and the Wave 5 spike on real data.
