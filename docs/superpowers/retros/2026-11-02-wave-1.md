# Wave 0–1 retro (2026-11-02)

## What worked
- **Reviews caught real defects every task.** The burden problem (keyless line wrong ~7 in 10), red-only turns dropped from success, held-out quota warnings, empty prompt ids corrupting labels, personal data in public docs. None would have been caught by the test suite alone.
- **Jev stayed the core.** Every change kept the Jev path's hits (7/27 → 10/27 labeled, 38/74 mined) while the keyless path shipped off-by-default when it missed its bar.
- **Fail-soft and privacy held** across five new hook paths.

## What did not
1. **All numbers are in-sample.** The work gate was tuned on the prompts it is scored on. Nothing has been measured on unseen prompts.
2. **Nothing records live.** Hooks run from a separate copy (`~/devpro/skills/skill-router`); Wave 1's purpose is real data, and it has none.
3. **Unverified harness contracts.** The Bash PostToolUse payload shape and `PostToolUseFailure` delivery were assumed, not observed.
4. **New per-call cost.** The Bash hook starts Python on every shell command (~70–100 ms).
5. **Hygiene is manual.** Personal identifiers and real prompts reached committed docs twice and were caught only by review; one fixture on public `main` still names the owner.
6. **Holdout side effects.** A held-out turn hides its quota warning; held-out names still count as "recently shown".
